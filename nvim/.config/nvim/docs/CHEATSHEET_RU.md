# Vim Cheat Sheet

## 1. Горизонтальные прыжки (Внутри строки)

Забудь про зажатую стрелочку вправо.

| Команда | Действие |
|---------|----------|
| `w` / `b` | К началу следующего / предыдущего слова |
| `e` | К концу текущего слова |
| `f` + `<символ>` | Find: прыжок ВПЕРЕД на указанный символ |
| `F` + `<символ>` | Find: прыжок НАЗАД на указанный символ |
| `t` + `<символ>` | Until: прыжок ДО символа (курсор встанет перед ним) |
| `0` | В начало строки (нулевой символ) |
| `^` | К первому значащему символу (начало кода) |
| `$` | В конец строки |

## 2. Вертикальные прыжки (По экрану)

Колесико мыши больше не нужно.

| Команда | Действие |
|---------|----------|
| `Ctrl + u` | Прокрутка на пол-экрана вверх (Up) |
| `Ctrl + d` | Прокрутка на пол-экрана вниз (Down) |
| `H` | High: прыжок в верхнюю строку на экране |
| `M` | Middle: в середину экрана |
| `L` | Low: в нижнюю строку на экране |
| `zz` | Центрировать экран вокруг курсора (очень удобно!) |

## 3. Глобальные прыжки (По файлу)

| Команда | Действие |
|---------|----------|
| `gg` | В начало файла |
| `G` | В конец файла |
| `/<текст>` | Поиск. После ввода жми `n` (далее) или `N` (назад) |
| `gd` | Go to Definition: прыжок к определению функции/переменной |
| `Ctrl + o` | Прыгнуть назад (в предыдущее место) |
| `Ctrl + i` | Прыгнуть вперед |
| `%` | Прыгнуть к парной скобке |

## 4. Секретное оружие: Текстовые объекты

Вместо выделения мышкой используй формулу:

**`(Действие) + (Внутри/Вокруг) + (Объект)`**

### Действия:
- `d` — удалить
- `y` — копировать
- `v` — выделить
- `c` — изменить

### Модификаторы:
- `i` — inside (внутри)
- `a` — around (вокруг со скобками)

### Примеры:

| Команда | Действие |
|---------|----------|
| `viw` | Выделить слово целиком (visual inside word) |
| `di"` | Удалить всё внутри кавычек (delete inside ") |
| `ca(` | Удалить всё в скобках и начать писать заново (change around () |
| `yiw` | Копировать слово под курсором |
| `das` | Удалить предложение со всеми пробелами вокруг |
| `ci{` | Удалить содержимое фигурных скобок и начать редактировать |
| `va[` | Выделить всё вокруг квадратных скобок включая сами скобки |

## 5. Бонус: Полезные комбинации

| Команда | Действие |
|---------|----------|
| `dd` | Удалить строку |
| `yy` | Копировать строку |
| `p` | Вставить после курсора |
| `P` | Вставить перед курсором |
| `u` | Отменить (Undo) |
| `Ctrl + r` | Повторить (Redo) |
| `.` | Повторить последнее действие |
| `>>` / `<<` | Сдвинуть строку вправо/влево |
| `=` | Автоформатирование (с текстовым объектом: `=ip` — отформатировать параграф) |
